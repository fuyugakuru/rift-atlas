Подпись творца

Наносящие урон способности Хвея против вражеских чемпионов отмечают их своей подписью на 4 секунд.
При попадании по отмеченному врагу второй наносящей урон способностью метка поглощается, создавая под ним взрыв, который детонирует после небольшой задержки, нанося магический урон 30 - 280 (+25% силы умений) всем врагам в радиусе действия.
Каждая способность может вызвать этот эффект только один раз для каждой цели.

Тема: катастрофа

Рисует видения катастрофы, наносящие врагам большой урон.
Разрушительный огонь: рисует пылающий огненный шар, который летит в выбранном направлении. Он взрывается при первом попадании по врагу, нанося 50 / 85 / 120 / 155 (+70% силы умений) плюс 4% / 5% / 6% / 7% от максимального здоровья цели в виде магии. урон всем врагам в области.
Severing Bolt: наносит молнию дальнего действия с задержкой в ​​выбранном месте, нанося магический урон 80 / 110 / 140 / 170 (+30% силы умений).
