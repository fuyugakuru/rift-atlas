# Публикация Rift Atlas на GitHub Pages

Репозиторий: https://github.com/fuyugakuru/rift-atlas
Адрес сайта после успешной публикации: https://fuyugakuru.github.io/rift-atlas/

Статические файлы сайта находятся в корне репозитория и в assets/. Публикация запускается автоматически при изменении ветки main. Источник в Settings → Pages: GitHub Actions. Тариф — GitHub Free, репозиторий публичный.

Рабочая полная версия с генераторами и данными: E:\Сайты\RiftAtlas. GitHub Pages публикует HTML, CSS, JavaScript, SVG и assets. Все переходы и значок сайта используют относительные пути.

Первый перенос использует части архива site-bundle.partNN и контрольную сумму. Workflow проверяет архив, распаковывает сайт, записывает исходные файлы в репозиторий и удаляет части из текущей ветки. При последующих обычных изменениях исходников этап импорта пропускается.

Для повторного переноса большого пакета сначала загружаются все части архива (они не запускают публикацию), последним — site-bundle.sha256. Обычные небольшие правки можно сохранять прямо в файлах репозитория. Статус публикации виден во вкладке Actions.
