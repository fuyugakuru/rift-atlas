# Как добавить видео скина

1. Открой файл **Видео скинов.json** в Visual Studio.
2. Найди чемпиона, например `akali`, затем название скина через **Ctrl+F**.
3. Между кавычками после названия вставь обычную ссылку YouTube:

```json
"Охотница за головами": "https://www.youtube.com/watch?v=EiCn7NSLP0Q"
```

4. Сохрани файл: **Ctrl+S**.
5. Дважды нажми **Обновить скины.cmd** в папке сайта.
6. На открытом локальном сайте нажми **Ctrl+F5**.

Пустая строка `""` означает, что видео нет. Поддерживаются ссылки youtube.com/watch, youtu.be и shorts. Можно вставить ссылку с отметкой времени, например `&t=30s`.

Не удаляй кавычки и запятые. При ошибке программа покажет название чемпиона и скина; страницы не изменятся. Ссылки проверяются по формату, доступность самого ролика нужно проверить в браузере.

HTML вручную редактировать не нужно. Код всех страниц разбит на строки и отступы; JSON со скинами внутри страницы тоже читаемый. Генераторы автоматически форматируют HTML после завершения. Форматировщик включён в проект и не требует скачиваний.

Основные файлы:

- `Видео скинов.json` — ссылки, которые ты добавляешь сам; этот файл имеет приоритет.
- `champion-skins.json` — полный каталог образов.
- `tools/items-page.html` — источник страницы предметов.
- `app.js` — поведение сайта и Google Analytics.
- `style.css` — внешний вид.

Изменения сначала появляются на ПК. Для обновления публичного сайта их нужно загрузить на GitHub. Можно менять файл «Видео скинов.json» прямо на GitHub: после сохранения коммита публикация автоматически применит ссылки к страницам. Если редактировал сайт прямо на GitHub, сначала синхронизируй локальную версию перед дальнейшей работой на ПК.
