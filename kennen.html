Смертельное оружие: урон умениями по вражескому чемпиону уменьшает получаемые им щиты на 3 секунды. Умения по области уменьшают щиты на 25% + 5% дополнительной силы умений, максимум на 45%. Навыки

Пассивное умение

Знак бури

При попадании по врагам способностями на них накладывается Знак бури на 6 секунд. При суммировании 3 враг настраивается на 1.25 секунд, а Кеннен получает энергию 25.
Оглушение врага несколько раз в течение 6 секунд уменьшает продолжительность оглушения до 0.5 секунд.

Значения через / — по уровням умения.

Числовые параметры: WildRiftFire ↗

Умение 1

Грохочущий сюрикен

Бросает сюрикен, нанося магический урон 75 / 140 / 205 / 270 (+75% силы умений) первому пораженному противнику.
Перезарядка7 / 6 / 5 / 4 сСтоимость60 / 55 / 50 / 45

Значения через / — по уровням умения.

Числовые параметры: WildRiftFire ↗

Умение 2

Скачок напряжения

Пассивно: каждая атака 5 наносит бонус 55 / 65 / 75 / 85 (+70% / 80% / 90% / 100% бонус силы атаки + 30% силы умений) бонуса. магический урон и накладывает Знак Шторма.
Активно: поражает ближайших врагов, пораженных Знаком бури, шоком, нанося магический урон 70 / 100 / 130 / 160 (+80% силы умений).
Перезарядка12 / 10 / 8 / 6 сСтоимость40 / 40 / 40 / 40

Значения через / — по уровням умения.

Числовые параметры: WildRiftFire ↗

Умение 3

Молниеносный рывок

Превращается в электрический шар на 2 секунд, становясь неспособным атаковать, но получая 100% дополнительной скорости движения и нанося 70 / 120 / 170 / 220 (+70% силы умений) магический урон врагам, через которых проходит. Бонусная скорость движения удваивается в течение первых 0.5 секунд.

Кеннен получает скорость атаки 50% /60% / 70% / 80% на 3 секунд после выхода из «Рыча молнии».

Получает энергию 40, когда «молниеносный рывок» впервые наносит урон врагу. Наносит 50% урона миньонам.
Перезарядка8 / 7 / 6 / 6 сСтоимость100 / 95 / 90 / 85

Значения через / — по уровням умения.

Числовые параметры: WildRiftFire ↗

Абсолютное умение

Убийственный шторм

Вызывает шторм, который дает Кеннену 20 / 40 / 60 броню и сопротивление магии и наносит 20 / 55 / 90 (+13% силы умений) магический урон каждые 0.5 секунды для 3 секунды.
Каждый последующий выстрел по той же цели наносит увеличенный на 10% урон.
Применяет 3 Знаки бури только к одной цели.
Перезарядка80 / 75 / 70 сСтоимость80 / 80 / 80

Значения через / — по уровням умения.
